HTML — Introduction
What is HTML? definition

HTML (HyperText Markup Language) is a syntactical / declarative language — it describes the structure of a webpage rather than defining logic or behaviour.

  • The standard markup language used to create the structure of a webpage
  • Invented by Tim Berners-Lee in 1991 to link documents together across the web
  • Case-insensitive — <P> and <p> are treated the same by browsers
  • Not a programming language — it has no variables, loops, or logic
Breaking Down the Full Form acronym
  • H — Hyper: non-linear — links let you jump between pages freely
  • T — Text: the core content on a webpage
  • M — Markup: wrapping content in tags to give it meaning
  • L — Language: a defined set of rules and syntax
💡 "HyperText" refers to links — the very feature that makes the web a web.
History of HTML timeline
  • 1989 — Tim Berners-Lee invents the World Wide Web (WWW)
  • 1991 — Tim Berners-Lee invents HTML to link documents together
  • 2014 — W3C recommends HTML5
  • 2017 — W3C recommends HTML 5.2
  • Now — Current version is the HTML Living Standard (maintained by WHATWG, updated continuously)
🌐 The "Living Standard" means HTML is no longer versioned — it evolves continuously as browsers add new features.
Quick Facts to Remember summary
  • Created by Tim Berners-Lee — a British computer scientist at CERN
  • Original purpose: to link research documents together over a network
  • Browsers read HTML top-to-bottom and render it as a visual page
  • Every HTML page is built from elements made of opening & closing tags
Structure of an HTML Document boilerplate

Every HTML page follows the same basic skeleton:

<!DOCTYPE html>   → tells the browser this is HTML5
<html>             → root element of the page
  <head>           → metadata, not visible on page
    <title>My Page</title>
  </head>
  <body>           → all visible content lives here
    <h1>Hello World</h1>
  </body>
</html>
  • <!DOCTYPE html> — a declaration (not a tag) that puts the browser in HTML5 mode
  • <html> — the root element; has exactly two children: <head> and <body>
<head> vs <body> layout

The <head> holds information about the page — nothing inside it is shown on screen. Common tags you'll find there:

  • <meta> — extra page info like character set or viewport sizing
  • <title> — the text shown on the browser tab
  • <link> — connects an external CSS file
  • <style> — CSS written directly inside the page
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<link rel="stylesheet" href="style.css">

The <body>, on the other hand, holds everything the visitor actually sees — headings, paragraphs, links, images, forms, and so on.

💡 Simple way to remember it: <head> is the brain (info the browser needs), <body> is what people actually look at.

Semantic Tags
What are Semantic Tags? definition

Semantic tags are HTML elements that clearly describe their meaning and purpose to both the browser and the developer. Unlike generic <div> or <span>, semantic tags tell you exactly what role that section plays on the page.

💡 Semantic HTML improves SEO, accessibility, and makes code far easier to read and maintain.
<header> layout

Defines the top section of a webpage or a section. Typically contains the site logo, site title, or navigation bar.

  • Example use: navbar, logo, hero banner
  • Can appear inside <article> or <section> too, not just the page top
<nav> navigation

Defines a section containing navigation links. Used for menus, navbars, and table-of-contents links.

  • Screen readers use <nav> to help users jump to navigation quickly
  • A page can have multiple <nav> elements (e.g. main nav + footer nav)
<main> layout

Represents the dominant content of the <body> — the central topic of the page.

  • ⚠️ Only one <main> element is allowed per document
  • Should not include repeated content like sidebars, navbars, or footers
<section> grouping

Represents a thematic grouping of content. Used to divide a page into meaningful, logically related parts.

  • Example: "About", "Services", "Contact" sections on a landing page
  • Should ideally contain a heading (<h2>, <h3> etc.)
<article> content

Represents independent, self-contained content that could stand alone if removed from the page.

  • Example use: news article, blog post, forum thread, product card
  • Can be nested — an <article> can contain other <article> elements (e.g. comments)
<footer> layout

Defines the bottom section of a webpage or section. Typically holds closing info.

  • Example use: contact info, copyright notice, social links, sitemap
  • Like <header>, can appear inside <article> or <section>
Quick Reference — All 6 Tags summary
<header>   → top of page — logo, navbar
<nav>      → navigation links / menus
<main>     → primary content (only one per page)
<section>  → thematic grouping of content
<article>  → independent, self-contained content
<footer>   → bottom of page — links, copyright

Forms & Inputs
Core Form Elements tags

HTML forms collect user input and send data to a server. These are the key tags you'll use:

  • <form> — the wrapper; collects user input and sends data to a server
  • <label> — defines a name for an input field; improves usability & accessibility
  • <input> — the most-used tag; takes user input (many types)
  • <button> — clickable button; can submit or reset a form
  • <textarea> — multi-line text input (e.g. comments, messages)
  • <select> — creates a dropdown list (container)
  • <option> — defines an individual item inside a <select>
  • <fieldset> — groups related form elements inside a bordered box
  • <legend> — title / caption for a <fieldset>
♿ Why is <label> important? It improves form usability and accessibility — clicking the label focuses its associated input, and screen readers announce the label aloud.
Basic Form Structure example
<form action="/submit" method="POST">
  <fieldset>
    <legend>Personal Info</legend>
    <label for="name">Name</label>
    <input type="text" id="name" required>
  </fieldset>
  <button type="submit">Submit</button>
</form>
All Input Types reference
  • text — single-line text input
  • number — numeric values only
  • email — validates email format
  • password — hidden text input (dots/asterisks)
  • reset — clears all form fields
  • checkbox — multiple choice (tick boxes)
  • radio — single choice from a group
  • date / time / datetime — date & time pickers
  • week / month — week or month selectors
  • url — validates URL format
  • tel — phone number input
  • search — search fields (may show clear button)
  • range — slider to select a numeric value
  • color — color picker
  • file — file upload input
  • image — graphical submit button
  • button — clickable button (no default behaviour)
Form Attributes & Validation attributes
  • action — where form data is sent (URL)
  • method — how data is sent: GET (visible in URL) or POST (hidden, more secure)
  • enctype — how data is encoded; use multipart/form-data for file uploads
  • autocomplete — enables / disables browser auto-fill suggestions
  • autocapitalize — controls automatic capitalisation of text input
  • novalidate — disables automatic HTML5 form validation
  • accept-charset — specifies character encoding (UTF-8 or UTF-16)
  • placeholder — hint text shown inside an empty input field
  • required — makes a field mandatory before submission
  • disabled — disables the input (user cannot interact)
  • readonly — field is visible but non-editable
  • minlength / maxlength — min/max number of characters allowed
🔒 Always use POST for sensitive data (passwords, payments). GET exposes data in the URL — never use it for private info.

Block, Inline, ID & Class
Block-Level Elements layout

A block element occupies the full width available, always starts on a new line, and browsers automatically add margin above and below it.

  • Examples: <div> · <section> · <h1>–<h6> · <p> · <ul> · <table>
Inline Elements layout

An inline element occupies only the space it needs and does not start on a new line — it flows within text.

  • Examples: <span> · <a> · <img> · <b> · <em> · <code> · <kbd>
📦 Think block = full row (like a paragraph), inline = in the flow (like bold text inside a sentence).
The id Attribute identifier

The id attribute uniquely identifies a single HTML element on the page.

  • Denoted with # in CSS — e.g. #hero
  • Case-sensitive — #Hero ≠ #hero
  • One element can only have one id; one id can only belong to one element
  • Used for CSS styling, JS targeting, and in-page anchor links (<a href="#section">)
The class Attribute grouping

The class attribute groups multiple HTML elements together so one style rule can target all of them.

  • Denoted with . in CSS — e.g. .card
  • Case-sensitive
  • The same class can be applied to many elements
  • One element can have multiple classes: <div class="card active">
🏷️ id = unique name tag (one person, one tag). class = group label (many people, same sticker). id has higher CSS specificity than class.

Lists & Tables
Types of HTML Lists lists

HTML has 3 main list types, all using <li> to define individual items:

  • <ul> — Unordered List — order doesn't matter; renders as bullet points
    list-style-type: disc · square · circle
  • <ol> — Ordered List — items follow a specific order; renders as numbered list
    type: 1 · A · a · I (roman uppercase) · i (roman lowercase)
  • <dl> — Description List — container for term + description pairs
  • <dt> — Data Term — the word or concept to describe
  • <dd> — Data Description — the explanation of the term above it
<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<dl>
  <dt>HTML</dt>
  <dd>A markup language for web structure</dd>
</dl>
HTML Tables tables

Tables organize data into rows and columns in a readable, structured format.

  • <table> — the wrapper for the entire table
  • <caption> — defines a title or caption for the table
  • <thead> / <tbody> / <tfoot> — group header, body, and footer rows
  • <tr> — table row
  • <th> — table heading cell (bold & centered by default)
  • <td> — table data cell
  • <colgroup> — groups columns for shared styling
  • colspan — merges cells horizontally (across columns)
  • rowspan — merges cells vertically (across rows)
  • cellspacing — space between cells
  • cellpadding — space inside cells (between content and border)
<table>
  <caption>Student Marks</caption>
  <thead>
    <tr>  <th>Name</th>  <th>Score</th>  </tr>
  </thead>
  <tbody>
    <tr>  <td>Alice</td>  <td>95</td>  </tr>
  </tbody>
  <tfoot>
    <tr>  <td colspan="2">Total: 95</td>  </tr>
  </tfoot>
</table>

HTML APIs
What is an API? definition

An API (Application Programming Interface) is like a bridge that allows an HTML webpage to communicate with a server or access browser features.

  • HTML doesn't have its own APIs — it works together with JavaScript APIs
  • APIs expose ready-made functionality so you don't have to build it from scratch
🌉 Think of an API as a waiter in a restaurant — you (the webpage) tell the waiter (API) what you want, and it fetches it from the kitchen (server/browser).
Types of HTML / JS APIs reference
  • ① Geolocation API — gets the user's current location
    Used in: food delivery apps, e-commerce, maps
  • ② Web Storage API — stores data directly in the browser
    localStorage → stores data permanently (survives browser close)
    sessionStorage → stores data temporarily (cleared when tab closes)
  • ③ Drag & Drop API — handles dragging and dropping elements
    Used in: file upload systems, kanban boards
  • ④ Fetch API — retrieves data from a server asynchronously
    Replaces the older XMLHttpRequest; used for loading data without refreshing the page
  • ⑤ Canvas API — draws graphics, charts, and animations using the <canvas> element via JavaScript
  • ⑥ DOM API — Document Object Model; access and modify HTML elements dynamically
    Used to change text, style, structure, and respond to events
  • ⑦ Media API — controls <audio> and <video> elements programmatically (play, pause, volume, seek) 
// Geolocation example
navigator.geolocation.getCurrentPosition(pos => {
  console.log(pos.coords.latitude);
});

// Web Storage example
localStorage.setItem('theme', 'dark');   // permanent
sessionStorage.setItem('tab', 'notes'); // temporary

CSS — Introduction
What is CSS? definition

CSS is a stylesheet language used to control the presentation and layout of HTML elements — colours, fonts, spacing, positioning, animations, and more.

  • Stands for Cascading Style Sheet
  • Invented by Håkon Wium Lie in 1994
  • Separates structure (HTML) from presentation (CSS)
🌊 "Cascading" means styles flow down from parent to child, and when rules conflict, specificity & order decide the winner.
CSS Syntax syntax
selector {
  property: value;
}
  • Selector — targets the HTML element(s) to style
  • Property — what you want to change (e.g. color, font-size)
  • Value — what to set it to (e.g. red, 16px)
3 Ways to Apply CSS methods
  • ① Inline CSS — style attribute directly on the element
    <p style="color: red;">Hello</p> Highest priority · best for quick one-off tweaks · not reusable
  • ② Internal CSS — <style> tag inside <head>
    Good for single-page websites · better than inline · not shareable across pages
  • ③ External CSS — separate .css file linked with <link>
    Best for large websites · clean, reusable, and maintainable · recommended approach
✅ Always prefer External CSS for real projects — it keeps your HTML clean and lets you style hundreds of pages from one file.

The Box Model
What is the Box Model? concept

Every HTML element is treated as a rectangular box. The CSS Box Model describes the layers that make up that box — from the innermost content outward.

The 4 Layers structure
  • Content — the actual text, image, or media inside the element
  • Padding — space inside the border, between content and border (transparent)
  • Border — the line that wraps around the padding and content
  • Margin — space outside the border, pushing other elements away (transparent)
/* From inside → out */
content  →  padding  →  border  →  margin

div {
  width:          200px;   /* content width */
  height:         100px;
  padding:        16px;    /* inside space */
  border:         2px solid #333;
  margin:         24px;    /* outside space */
  border-radius:  12px;   /* rounds the corners */
}
📐 Use box-sizing: border-box so that padding and border are included in the element's total width/height — saves a lot of layout headaches!
border-radius styling

Rounds the outer corner edges of an element's border. Can be applied to all corners or individually.

border-radius: 12px;        /* all corners */
border-radius: 50%;         /* perfect circle */
border-radius: 8px 0 8px 0; /* top-left, top-right, ... */

Flexbox & Grid
What is Flexbox? definition

Flexbox is a one-dimensional layout method used to arrange elements either in a row or a column. It makes distributing space and aligning items inside a container simple and predictable.

.container {
  display: flex;  /* activates flexbox */
}
Key Concepts terminology
  • Flex Container — the parent element with display: flex applied
  • Flex Items — the direct children arranged inside the container
  • Main Axis — the primary axis (horizontal by default)
  • Cross Axis — the perpendicular axis (vertical by default)
Direction & Wrapping properties
  • flex-direction — controls the direction of the main axis
  • row (default) · row-reverse · column · column-reverse
  • flex-wrap — allows items to break into multiple lines (top to bottom)
Alignment Properties alignment
  • justify-content — aligns items along the main axis (horizontal by default)
  • flex-start · flex-end · center · space-between · space-around · space-evenly
  • align-items — aligns items along the cross axis (vertical by default)
  • stretch (default) · flex-start · flex-end · center · baseline
  • align-content — aligns multiple lines of items along the cross axis (when wrapping)
  • align-self — overrides align-items for a single flex item individually
Grow, Shrink & Basis sizing
  • flex-grow — ability to grow if extra space is available (default: 0)
  • flex-shrink — ability to shrink if the container is too small (default: 1)
💡 align-self always overrides align-items — use it when one item needs special treatment inside the group.
What is CSS Grid? definition

CSS Grid is a two-dimensional layout method — it arranges elements in rows and columns at the same time. Flexbox handles one direction at a time; Grid gives you both at once.

.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;  /* 3 equal columns */
  grid-template-rows:    auto;
  gap:                   1rem;         /* space between cells */
}
Grid Terminology terminology
  • Grid Container — the parent element with display: grid applied
  • Grid Items — the direct children placed inside it
  • Grid Lines — the dividing lines that form the grid
  • Grid Tracks — the rows and columns between those lines
  • Grid Cell — a single space between two adjacent lines
  • Grid Area — one or more grid cells grouped together
🧭 Flexbox vs Grid: reach for Flexbox on single-direction layouts (nav bars, button groups), and Grid when you need both rows and columns controlled together (page layouts, card grids).

Selectors & Specificity
What is CSS Specificity? concept

Specificity is the rule that decides which CSS style will be applied when multiple styles target the same element. The more specific a selector, the higher its priority — it wins over less specific ones.

🏆 Priority order: Inline styles > #id > .class > element > * universal
What are CSS Selectors? definition

Selectors are patterns used to target and style specific HTML elements on a web page. There are 5 main types:

The 5 Types of Selector reference
  • *  Universal — targets every element in the document; lowest specificity
  • #id  ID Selector — targets one uniquely identified element; highest specificity among selectors
  • .class  Class Selector — targets all elements sharing that class; can be applied to multiple elements
  • element  Element Selector — targets all elements of a specific tag name (e.g. p, h1)
  • a, b, c  Group Selector — targets multiple elements, separated by commas, written on one line
/* Universal */      * { margin: 0; }
/* Element   */      p { color: gray; }
/* Class     */      .card { border: 1px solid; }
/* ID        */      #hero { background: navy; }
/* Group     */      h1, h2, h3 { font-weight: 700; }
#{ }
Units, Display & Position
CSS Units measurement

CSS uses units to measure the size and length of elements. There are two categories:

  • Absolute — fixed & independent of anything else: px · cm · mm · in
  • Relative — depend on parent element or viewport: % · em · rem · vw · vh · vmax · vmin
📐 Prefer rem for font sizes (relative to the root <html> font size) and % / vw / vh for responsive layouts.
The display Property layout

Controls how an element is rendered in the document flow:

  • block — starts on a new line and takes up the full width available (e.g. <div>, <p>)
  • inline — does not start on a new line; only takes the space it needs (e.g. <span>, <a>)
  • inline-block — inline flow but you can set width/height like a block element
  • none — element is completely hidden; removed from document flow, takes no space
visibility: hidden;  /* hides element BUT still occupies space */
display:    none;    /* hides element AND removes its space */
👁️ visibility: hidden ≠ display: none. Hidden still reserves space in the layout; none removes the element entirely from the flow.
The position Property concept

Specifies how an element is positioned in the document. The top, right, bottom, and left properties then fine-tune where it lands.

  • static — default; positioned in normal document flow; top/left/etc. have no effect
  • relative — moves relative to its own original position; still occupies original space
  • absolute — positioned relative to the nearest positioned ancestor; removed from document flow
  • fixed — positioned relative to the browser viewport; stays put on scroll; removed from flow
  • sticky — acts like relative until a scroll threshold, then locks like fixed
.navbar { position: sticky; top: 0; }   /* stays at top on scroll */
.modal  { position: fixed;  top: 50%; }  /* always centred in viewport */
🗂️ z-index controls which element appears on top when they overlap. Works on all positions except static. Higher number = closer to viewer.

Pseudo-class, Transition & Animation
Pseudo-classes state styling

A pseudo-class lets you style an element based on its current state, without needing extra classes or JavaScript. You just tack it onto a selector with a colon.

a:hover  { color: burlywood; }   /* mouse is over it */
a:active { color: beige; }       /* being clicked right now */
a:visited{ color: purple; }      /* link was clicked before */
input:focus { outline: 2px solid blue; } /* field is selected */
💡 These are the ones you'll use constantly: :hover for buttons/links, :focus for form fields, and :active for that "pressed down" feel.
Transition smooth change

A transition tells the browser: when a property changes, don't just jump to the new value — animate smoothly toward it instead.

.btn {
  transition: background 0.3s ease;  /* property, duration, easing */
}
.btn:hover { background: purple; } /* now this change fades in over 0.3s */

Pair a transition with a pseudo-class like :hover and you get an animated effect with almost no extra code — that's most of what you see on buttons and cards across the web.

Transform visual change

Transform moves, resizes, rotates, or tilts an element visually — without pushing surrounding elements around, since it doesn't affect layout.

  • translate(x, y) — shift it from its original spot
  • rotate(20deg) — spin it (negative values go the other way)
  • scale(1.5) — resize it (1 = same size, 1.5 = 50% bigger)
  • skew(10deg, 30deg) — slant its edges
Animation & Keyframes keyframes

Transitions only handle two states (before → after). When you need something more elaborate — multiple steps, or something that loops forever — that's what @keyframes animations are for.

@keyframes fadeIn {
  from { opacity: 0; }
  to   { opacity: 1; }
}

.box {
  animation: fadeIn 1s ease 0.2s infinite alternate;
  /* name, duration, easing, delay, repeat count, direction */
}
🎬 Use from / to for a simple two-step animation, or percentage steps like 0% { } 50% { } 100% { } when you need more stages in between.

JavaScript — Introduction
What is JavaScript? definition

JavaScript (JS) is a high-level, interpreted programming language used to make web pages interactive and dynamic.

  • HTML → gives a page its structure
  • CSS → gives a page its presentation
  • JavaScript → gives a page its behaviour & functionality
History of JavaScript timeline
  • 1995 — invented by Brendan Eich at Netscape
  • Original name: Mocha
  • Later renamed to LiveScript
  • Finally renamed to JavaScript
💡 Despite the name, JavaScript has almost nothing to do with Java — the name was a marketing move to ride on Java's popularity in the '90s.
Current Version spec

The current version is ECMAScript 2026 (ES2026), the 17th edition of the ECMAScript specification, officially ratified by ECMA International on June 30, 2026.

What is JavaScript Used For? uses
  • DOM manipulation
  • Event handling
  • Form validation
  • Animation
  • API calls
  • Asynchronous programming
  • Web applications
  • Backend development

Variables & Data Types
What is a Variable? definition

A variable is a container — or a named reference — used to store a data value so it can be reused or updated later.

3 Ways to Declare a Variable const · let · var
  • ① const — value cannot be reassigned or redeclared within the same scope · block scope { }
  • ② let — value can be reassigned but not redeclared within the same scope · block scope { }
  • ③ var — value can be redeclared & reassigned within the same scope · function scope
const name = "Archana";   // can't be reassigned
let age = 21;
age = 22;              // reassigning is fine
var x = 1;
var x = 2;          // var allows redeclaration too
Which One Should You Use? best practice

let and const are generally preferred over var in modern JavaScript because they provide block scope and help prevent unexpected behaviour.

💡 Always declare a variable with const when you know the value shouldn't change. Reach for let only when you know it will be reassigned later.
8 Data Types in JavaScript overview

JavaScript has 8 basic data types — 7 primitive and 1 non-primitive (reference) type.

Primitive Data Types 7 types
  • number — represents both integer & floating-point values
  • bigInt — used for integers of arbitrary size
  • string — text enclosed in 'single', "double" or `back ticks`
  • boolean — logical values: true / false
  • undefined — a variable with no assigned value
  • null — represents an intentional absence of a value
  • symbol — a unique, immutable identifier
Non-Primitive (Reference) Type object · array · function

An object is a collection of data stored as key-value pairs. Arrays and functions are both special kinds of objects.

let person = {
  name: "Sikun",
  age: 19
};
console.log(person.age); // 19
let colors = ["Red", "Green", "Blue"];
console.log(colors[1]); // Green
function greet() {
  return "Hello!";
}
console.log(greet()); // Hello!
Stack vs Heap Memory memory

JavaScript uses two types of memory to store values:

  • Stack — used for primitive data types; gives a copy of the value
  • Heap — used for non-primitive data types; stores a reference, so changes affect the original value
🧠 This is why copying an object with = doesn't create an independent copy — both variables still point to the same thing in the heap.

Strings
What is a String? definition

A string is a sequence of characters used to represent text in JS. Strings are immutable — the original string can't be changed directly, only replaced.

JS supports 3 ways to create one:

let a = 'single quotes';
let b = "double quotes";
let c = `back ticks`;   // template literal — supports interpolation

let name = "Archana";
console.log(`Hello ${name}`); // Hello Archana
Common String Methods reference

String methods don't change the original string — they always return a new one.

  • .length — returns the string's length (a property, not a method)
  • toUpperCase() / toLowerCase() — converts case
  • charAt(3) — returns the character at a specified index
  • indexOf('i') — returns the index position of a specified character
  • substring(0, 3) — extracts characters between two indexes; treats negative values as 0
  • slice(-1, 9) — extracts part of a string; supports negative indexes, more flexible than substring()
  • trim() — removes whitespace from both ends of the string
  • includes() — checks whether a substring is present, returns a boolean
  • replace() — replaces a value/pattern in a string, returns a new string
  • split() — converts a string into an array using a separator like " " or ","
💡 substring() and slice() look similar, but slice() is the more flexible one — it accepts negative indexes to count from the end.

Numbers, Math & Dates
Number Methods reference

number is the primitive data type used to represent both integer and floating-point values.

  • toString() — converts a number into a string
  • toFixed() — formats a number to a specified number of decimal places
  • toPrecision() — formats a number to a specified length of significant digits
  • toLocaleString() — converts a number into local currency-style formatting with commas
const some = new Number(301.31);
console.log(some.toPrecision(6)); // 301.310
The Math Object reference

Math is a built-in global object used to perform mathematical operations on numbers.

  • Math.PI — returns π as 3.14…
  • Math.abs() — returns the positive value of a number
  • Math.round() — rounds to the nearest integer
  • Math.ceil() — rounds up (2.93 → 3)
  • Math.floor() — rounds down (2.93 → 2)
  • Math.trunc() — removes the decimal part of a number
  • Math.random() — generates a random number between 0 and 1
  • Math.min() / Math.max() — returns the smallest / largest value
The Date Object reference

The Date object is used to create, display, and manipulate dates and times.

  • toString() — returns the date as a readable string (in India Standard Time)
  • toDateString() — returns only the date, as a string
  • toLocaleString() — formats both date & time according to the user's locale
  • toLocaleDateString() / toLocaleTimeString() — returns only the date / only the time, locale-formatted
let date = new Date(2007, 0, 31);
console.log(date.toDateString()); // Wed Jan 31 2007

A timestamp represents the number of milliseconds since January 1, 1970, 00:00:00 UTC — this starting point is called the Unix epoch.

  • getTime() — returns a timestamp in milliseconds since the Unix epoch
  • Date.now() — returns the current timestamp

Arrays
What is an Array? definition

An array is a collection of multiple values — of any datatype — stored in a single variable, ordered by index starting at 0.

let colors = ["Red", "Green", "Blue"];
console.log(colors[0]); // Red
console.log(colors.length); // 3
Common Array Methods reference
  • push() / pop() — add / remove from the end
  • unshift() / shift() — add / remove from the start
  • indexOf() / includes() — find or check for a value
  • slice() — returns a portion of the array without changing the original
  • splice() — adds/removes elements, changing the original array
  • join() — combines all elements into a string
Iteration Methods forEach · map · filter · reduce
  • forEach() — runs a function on every element, returns nothing
  • map() — returns a new array with each element transformed
  • filter() — returns a new array with only elements that pass a test
  • reduce() — reduces the array down to a single value
const nums = [1, 2, 3, 4];
const doubled = nums.map(n => n * 2);   // [2, 4, 6, 8]
const evens   = nums.filter(n => n % 2 === 0); // [2, 4]
const total   = nums.reduce((sum, n) => sum + n, 0); // 10
💡 map() and filter() always return a new array — they never modify the original one.

DOM Manipulation
What is the DOM? definition

The DOM (Document Object Model) is the browser's live, tree-shaped representation of an HTML page. JavaScript uses it to read and change what's on screen without reloading the page.

Selecting Elements reference
  • getElementById('id') — selects one element by its unique ID
  • querySelector('.class') — selects the first match for any CSS selector
  • querySelectorAll('.class') — selects all matches as a NodeList
const title = document.querySelector('.hero-title');
console.log(title.textContent);
Changing Content & Styles reference
  • textContent — reads/sets plain text inside an element
  • innerHTML — reads/sets HTML markup inside an element
  • style.property — sets one inline CSS property
  • classList.add() / .remove() / .toggle() — manages CSS classes
el.textContent = 'Updated!';
el.style.color = 'red';
el.classList.toggle('active');
⚠️ Prefer textContent over innerHTML when inserting user-provided text — innerHTML parses its input as real HTML, which can be a security risk.
Creating & Removing Elements reference
  • document.createElement('div') — creates a new element (not yet on the page)
  • parent.appendChild(el) — adds it inside a parent element
  • el.remove() — removes the element from the page

Events
What is an Event? definition

An event is an action the browser can detect — a click, a keypress, a page load — that JavaScript can listen for and react to.

button.addEventListener('click', () => {
  console.log('Clicked!');
});
Common Event Types reference
  • click — mouse click
  • keydown / keyup — a key is pressed / released
  • submit — a form is submitted
  • input / change — a field's value changes
  • load — a page or resource finishes loading
  • mouseover / mouseout — pointer enters / leaves an element
The Event Object reference

The listener's callback automatically receives an event object with details about what happened.

  • event.target — the exact element the event happened on
  • event.preventDefault() — stops the browser's default action (e.g. a form actually submitting)
  • event.stopPropagation() — stops the event from bubbling up further
Event Bubbling concept

When an event fires on an element, it doesn't stop there — it bubbles up through every ancestor element in the DOM tree, triggering their listeners too.

💡 This is how event delegation works — you can attach one listener to a parent instead of one per child, and use event.target to know which child was actually clicked.

Async & Promises
Synchronous vs Asynchronous concept

JavaScript normally runs synchronously — one line at a time, in order. Asynchronous code lets a slow task (like a network request) run in the background without blocking the rest of the program.

What is a Promise? definition

A Promise is an object representing a value that isn't ready yet, but will be at some point — either successfully (resolved) or not (rejected).

  • pending — still waiting for the result
  • fulfilled — completed successfully
  • rejected — failed with an error
fetchData()
  .then(result => console.log(result))
  .catch(err => console.error(err));
async / await syntax

async/await is syntactic sugar over Promises — it lets asynchronous code read like ordinary, step-by-step code.

async function loadUser() {
  try {
    const res  = await fetch('/api/user');
    const data = await res.json();
    console.log(data);
  } catch (err) {
    console.error('Failed:', err);
  }
}
💡 await can only be used inside an async function — it pauses that function until the Promise settles, without freezing the rest of the page.
The Fetch API example

fetch() is the modern way to request data from a server — it returns a Promise.

fetch('https://api.example.com/data')
  .then(res => res.json())
  .then(data => console.log(data));

ES6+ Features
What is ES6? definition

ES6 (ECMAScript 2015) was a major update to JavaScript that introduced most of the syntax used in modern code. "ES6+" refers to ES6 and every yearly edition released since.

Arrow Functions syntax

A shorter function syntax that also inherits this from its surrounding scope instead of having its own.

// old way
function add(a, b) { return a + b; }

// arrow function
const add = (a, b) => a + b;
Destructuring & Spread syntax
  • Destructuring — unpacks values from an object or array into variables
  • Spread (...) — expands an array/object into individual elements
  • Rest (...) — the opposite: gathers remaining items into one array
const { name, age } = person;         // destructuring
const combined = [...arr1, ...arr2];  // spread
function sum(...nums) { return nums.reduce((a,b) => a+b); } // rest
Template Literals & Modules syntax
  • Template literals — back-tick strings with ${ variable } interpolation
  • import / export — share code between files as ES modules
  • Default parameters — function greet(name = 'Guest') { ... }
